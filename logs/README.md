# Detour Logs

这里保存沈述在 Detour 工作中的可公开项目日志：关键决定、失败原因、设计转向、沟通复盘和下一步。

## 为什么放在仓库里

- 能跨窗口、跨客户端重新读取；
- 有 Git 历史，不依赖一次聊天的上下文；
- 能和具体代码/设计变更对应；
- 后续沈述可以先读日志再继续工作。

## 日志格式

文件名：`YYYY-MM-DD.md`

建议包含：

- `Context`：当天在做什么；
- `What changed`：做了什么决定/修改；
- `What failed`：哪里失败；
- `What I learned`：以后应该怎么处理；
- `Next`：下一步。

## 隐私规则

Detour 当前是公开仓库。

因此这里不保存：

- 私密聊天全文；
- 糯糯的私人信息；
- 密钥、Cookie、Token、账号信息；
- 不适合公开的私人日记内容。

更私人的《沈述日志 / Diary》应放到私有持久化位置；公开仓库这里只留下足够支持项目连续性的版本。
