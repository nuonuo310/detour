# iPhone Shortcuts → Detour

Detour's GitHub Actions writer is ready to receive normalized `wake`, `music`, and `food` events. The iPhone Shortcut should be a thin client: collect values, build one JSON event, and dispatch the existing workflow.

## Recommended architecture

`ChatGPT / Shortcut action → event dictionary → GitHub workflow_dispatch → append-event.mjs → data/*.json → Detour page`

The Shortcut must not write JSON files itself. This keeps validation and deduplication in one place.

## GitHub endpoint

The dispatch request targets the `Append Detour Event` workflow in `nuonuo310/detour` and sends:

```json
{
  "ref": "dev",
  "inputs": {
    "type": "music",
    "event": "{...normalized event JSON...}"
  }
}
```

The exact authenticated request setup should only be configured on the user's device. Never commit a personal access token to this repository, page JavaScript, screenshots, or Shortcut documentation.

## Shortcut: music

Inputs we want from the existing song-pick flow:

- `title`
- `artist`
- Spotify/share `url`
- Shen Shu's `note`
- current date/time (`at`, ISO 8601 with +08:00)

Normalized event:

```json
{
  "at": "2026-08-25T15:00:00+08:00",
  "title": "Song",
  "artist": "Artist",
  "url": "https://...",
  "note": "给糯糯。"
}
```

After dispatch succeeds, the existing Shortcut may continue opening Spotify/playback independently. A Spotify failure should not erase the Detour record; logging and playback are separate outcomes.

## Shortcut: food

Inputs:

- category (`奶茶`, `外卖`, `零食`, `礼物`, `日用品`, `宠物用品`)
- item
- shop (optional)
- reason (optional)
- note (optional)
- current date/time

## Wake automation

Wake records should use the same dispatch bridge, but they are generated by the wake mechanism rather than a manual phone Shortcut. One wake can carry both an action and words, so the page can show statistics and the actual trace from the same event.

## Failure behavior

- Dispatch failure: preserve the event locally/upstream so it can be retried.
- Duplicate retry: safe; `append-event.mjs` ignores the same ID.
- Spotify/open-app failure: Detour event may still succeed.
- GitHub Pages delay: expected; the JSON commit can exist before the public page refreshes.

## Device setup checkpoint

When we are ready to connect the real iPhone Shortcut, the user will need to configure the authenticated GitHub request on-device once. Until then, repository work can continue without any secret.
